# [W01][sim] MuJoCo setup — 이석민

## Environment
- OS: Windows 11 (ThinkPad X1 Carbon Gen 11, no discrete GPU)
- Python 3.14 / mujoco 3.15.0 / gymnasium 1.4.0
- Install: `pip install "gymnasium[mujoco]"`

## What actually ran
- `python week1_mujoco_demo.py` → `Humanoid-v5`, random policy, 3000 steps
- obs dim: 348 / action dim: 17
- 결과: 124 episodes, 모두 16~46 step 안에 넘어짐
